# 04 视觉规范

> 项目：Business002 — 小学生学习家庭工作台
> 任务编号：DEV-B002-001 ｜ 文档版本：v0.1 ｜ 状态：等待 QA
> 上游文档：`00_设计任务说明.md`、`02_页面状态矩阵.md`
> 适用：本版仅**浅色模式**、仅中文。不预留深色变量，不做多语言长度适配。

---

## 1. 视觉基调

| 端 | 三个关键词 | 一句话描述 |
|---|---|---|
| 孩子端 | 明亮、圆润、大 | 像一个做得很好玩的卡片游戏，但**没有游戏化的压力**（无倒计时、无连击、无排行） |
| 家长端 | 清爽、克制、密 | 像一个安静的家庭记账本，重点在"看得清、点得准"，不在"好看" |

**两端共享的底层**：同一个中性灰阶、同一套间距刻度、同一套动效时长。差异只体现在主色、圆角、字号、信息密度上。这样做的好处是：Trae 只需要换一层 token，不需要写两套组件。

**一条总则**：孩子端的视觉丰富度靠**形状与色彩**，不靠**装饰**。不用渐变背景堆叠、不用阴影多层嵌套、不用贴纸/星星/光效铺满屏幕——装饰一多，孩子就分不清哪个能点。

## 2. 色彩

### 2.1 中性色阶（两端共用）

| Token | 值 | 用途 |
|---|---|---|
| `--ink-900` | `#1D2129` | 主文字（孩子端标题、家长端正文） |
| `--ink-700` | `#3D4450` | 次级标题 |
| `--ink-500` | `#5C6370` | 辅助文字、说明 |
| `--ink-300` | `#9AA0A9` | 占位符、禁用文字 |
| `--line` | `#E5E7EB` | 分割线、卡片描边 |
| `--bg` | `#F7F8FA` | 页面底色 |
| `--surface` | `#FFFFFF` | 卡片、弹层 |

**对比度校验**：`--ink-900` on `--surface` = 15.2:1；`--ink-500` on `--surface` = 6.4:1；`--ink-500` on `--bg` = 6.1:1。均 ≥ 4.5:1，正文合规。`--ink-300` 仅用于占位符，不承载信息，允许 3.0:1。

| `--c-success` | `#1FA971` | 已通过对勾、已完成标签 | 3.4:1（大图标可用）→ 文字用 `--c-success-ink` |

**红线**：孩子端**不使用红色**（`#D93F3F` 及任何 hue 在 350°~10° 的色）。唯一例外是 E3 级致命错误页的错误图标，且需降饱和至 `#C86B6B`。

|---|---|---|---|
| `--p-primary` | `#2456C7` | 主按钮、当前 Tab | 7.0:1 ✅ |
| `--p-primary-dark` | `#1B45A3` | 按下态 | 9.1:1 |
| `--p-primary-soft` | `#EDF1FB` | 选中底、信息条 | — |
| `--p-success` | `#12805C` | 已通过标签 | 5.1:1 ✅ |
| `--p-success-soft` | `#E7F5EF` | 已通过底 | — |
| `--p-warn` | `#B4711A` | 待确认标签、备份提醒文字 | 5.3:1 ✅ |
| `--p-warn-deep` | `#8A5300` | L2 强提醒文字 | 7.3:1 ✅ |
| `--p-warn-soft` | `#FDF3E2` | L1 提醒条底 | — |

**家长端为什么不用孩子端的蓝**：两端主色必须能一眼区分身份（`#2E7DF7` 明快 vs `#2456C7` 沉稳）。同一设备来回切换时，颜色是唯一的即时身份信号，比标题文字更快被识别。

### 2.4 状态色映射（全站唯一口径）

| 语义 | 孩子端 | 家长端 |
|---|---|---|
| 待完成 | 中性（`--ink-900` 卡面 + 主色按钮） | `--p-muted` 灰标签 |
| 待家长确认 | 主色 `--c-primary` 只读标签 | `--p-warn` 琥珀标签 |
| 已通过 | `--c-success(-ink/-soft)` 绿 | `--p-success(-soft)` 绿 |
| 需修改 | `--c-revision` 紫 | `--p-revision` 紫 |
| 补交 | `--c-late` 灰 | `--p-muted` 灰 |

**一色一义**：绿=通过、紫=退回、琥珀=等待/注意、灰=未开始/迟到/停用、红=仅删除确认。任何页面不得借用状态色做装饰。

## 3. 字体与字号

### 3.1 字体栈

```
-fruit: -apple-system, "PingFang SC", "Microsoft YaHei", "Noto Sans SC", "Helvetica Neue", sans-serif;
-mono:  ui-monospace, "SF Mono", "Consolas", monospace;
```

- 不使用任何需网络加载的字体（PWA 离线优先，字体必须本地可用）。
- **数字使用 `font-variant-numeric: tabular-nums`**：星星数、经验值、连续天数会频繁变化，非等宽数字会导致跳动。

### 3.2 孩子端字号阶梯

| 用途 | 字号 / 行高 | 字重 |
|---|---|---|
| 宠物等级、连续天数（大数字） | 34 / 40 | 700 |
| 页面标题（「要做的」） | 24 / 32 | 700 |
| 任务名 | 20 / 28 | 600 |
| 正文 / 说明 | 17 / 26 | 400 |
| 按钮文字 | 18 / 24 | 600 |
| 标签、角标 | 14 / 20 | 500 |
| 最小字号 | **14px**（仅限标签，正文不得小于 17px） | — |

### 3.3 家长端字号阶梯

| 用途 | 字号 / 行高 | 字重 |
|---|---|---|
| 页面标题 | 22 / 30 | 600 |
| 区块标题 | 17 / 24 | 600 |
| 正文 | 15 / 22 | 400 |
| 表格/列表主文字 | 15 / 22 | 500 |
| 辅助说明 | 13 / 18 | 400 |
| 按钮 | 16 / 22 | 600 |
| 最小字号 | **12px**（仅限时间戳） | — |

**为什么两端字号差这么多**：孩子端的读者可能只有 7 岁，且很多在平板上用手指点；家长端读者是成年人，且需要在一屏看到更多信息（多个孩子、多条待确认）。强行统一字号会同时伤害两端。

## 4. 间距、圆角、阴影

### 4.1 间距刻度（4 的倍数，全站唯一）

`4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 56`

| 场景 | 孩子端 | 家长端 |
|---|---|---|
| 页面左右边距 | 20 | 16 |
| 卡片内边距 | 20 | 16 |
| 卡片间距 | 16 | 12 |
| 区块间距 | 32 | 24 |
| 按钮组内间距 | 12 | 8 |

**禁止出现非刻度值**（如 14px、18px、22px）。这条规则的作用是防止实现时出现"各处差 2px"的错位感。

### 4.2 圆角

| Token | 孩子端 | 家长端 | 用途 |
|---|---|---|---|
| `--r-card` | 24 | 12 | 卡片、弹层 |
| `--r-btn` | 999 | 999 | 主按钮（胶囊） |
| `--r-small` | 16 | 8 | 图标容器、输入框 |
| `--r-badge` | 999 | 6 | 状态标签（孩子端胶囊，家长端小圆角矩形） |
| `--r-bar` | 6 | 6 | 经验条、进度条 |

### 4.3 阴影（仅两级，禁止叠加）

| Token | 值 | 用途 |
|---|---|---|
| `--shadow-card` | `0 2px 8px rgba(29,33,41,0.06)` | 孩子端卡片 |
| `--shadow-card-p` | `0 1px 3px rgba(26,29,35,0.08)` | 家长端卡片 |
| `--shadow-modal` | `0 8px 32px rgba(29,33,41,0.16)` | 弹层 |

**禁止**：多层阴影、彩色阴影、内阴影。孩子端卡片靠"白底 + 圆角 + 单层浅阴影"与灰底页面区分，不靠粗描边。

## 5. 触控目标（小学生可用性硬指标）

| 元素 | 孩子端 | 家长端 |
|---|---|---|
| 主按钮高度 | **56px**（最小 52px） | 48px |
| 次按钮高度 | 48px | 40px |
| 图标按钮点击区 | 48 × 48 | 44 × 44 |
| 任务卡整卡可点区 | **≥ 88px 高** | 卡片可点 |
| 相邻可点元素最小间距 | **12px** | 8px |
| 底部 Tab 高度 | 64px + 安全区 | 56px + 安全区 |
| 数字键盘按键（PIN） | 72 × 72，间距 12 | 同左 |
| 滑动手势 | **不作为任何功能的唯一入口** | 同左 |

**规则说明**：88px 的任务卡高度不是为了好看，是因为 7 岁孩子的手指落点误差可达 ±15px，按钮太密会连续误点。同理，任何"只能滑动才能触发"的操作都必须有显式按钮替代。

## 6. 孩子端 vs 家长端的视觉区分原则

| 维度 | 孩子端 | 家长端 |
|---|---|---|
| 主色 | `#2E7DF7`（明快） | `#2456C7`（沉稳） |
| 圆角 | 大（24/32） | 中（12/16） |
| 字号 | 大（任务名 20px） | 中（正文 15px） |
| 信息密度 | 一屏最多 4 张卡 | 一屏可 8~10 行 |
| 图形 | 有（头像、宠物、图标） | 极少（仅头像与状态图标） |
| 装饰 | 允许柔和渐变、圆润插画 | 纯色块，无插画 |
| 动效 | 允许（仅升级） | 几乎无（仅条带淡出） |
| 语气 | 对话式（「我做完啦」） | 陈述式（「通过」） |
| 标题风格 | 问句/短句（「今天是谁呀？」） | 名词短语（「任务管理」） |

**判定准则**：把任意一屏截图去掉文字后，一个陌生人应该能立刻判断"这是给孩子的还是给家长的"。如果判断不出来，说明区分不足。

**共同禁止**：
- ❌ 不用 emoji 作为功能图标（不同系统渲染差异大，且显得不专业）。宠物形象除外（见 8 节），但也应为内嵌 SVG 而非 emoji。
- ❌ 不用装饰性渐变背景大面积铺色。
- ❌ 不用描边型图标 + 填充型图标混搭（同一页面内统一一种）。

## 7. 关键组件规格

### 7.1 任务卡（孩子端，本产品最重要的组件）

```
┌─────────────────────────────────────────┐
│  ┌────┐                                  │
│  │icon│  背古诗                    [补交] │  ← 20/28 600，标签 14
│  └────┘  每天 · 3 颗星星                 │  ← 17/26 400 辅助
│                                          │
│         ┌──────────────────────────┐    │
│         │      我做完啦             │    │  ← 高 56，胶囊，主色实心
│         └──────────────────────────┘    │
└─────────────────────────────────────────┘
   圆角 24 / 内边距 20 / 白底 / 单层阴影
```

| 状态 | 规格 |
|---|---|
| `todo` | 上述形态，按钮实心 |
| `submitted` | 整卡 `opacity: .85`；按钮替换为**无背景只读标签**「已交，等确认」（灰字 + 琥珀小点） |
| `approved` | 卡片底 `--c-success-soft`；左侧对勾替代图标位；**移除按钮**；星星数改为`已得 3 颗` |
| `revision` | 卡片底 `--c-revision-soft`；左侧循环箭头图标；按钮文案「我改好了」；下方展开原因区（`--c-revision` 左边框 3px + 原因文本 17px） |

**卡片高度**：`todo` ≈ 148px，`approved` ≈ 104px（移除按钮后压缩），保证一屏能看到 4 张。

### 7.2 主按钮

| 属性 | 孩子端 | 家长端 |
|---|---|---|
| 高度 / 圆角 | 56 / 999 | 48 / 999 |
| 背景 | `--c-primary` | `--p-primary` |
| 文字 | 白，18/600 | 白，16/600 |
| 宽度 | 撑满卡片内容宽 | 撑满容器 |
| 禁用 | 背景 `#C9CDD4`，文字白，无阴影 | 同 |
| 加载 | 保持宽度，内部换为「确认中…」文字，**不显示 spinner 图标**（避免布局跳动） | 同 |

**为什么不用 spinner**：按钮内 spinner 需要固定尺寸容器，实现时容易出现"文字→spinner→文字"的宽度跳变。用文字变化最稳定，且中文"确认中…"本身信息量更足。

### 7.3 状态标签（badge）

| 类型 | 孩子端 | 家长端 |
|---|---|---|
| 补交 | 胶囊，`--c-late-soft` 底 / `--c-late` 字 / 14px / 内边距 4×10 | 小圆角，`--p-muted` 字 / 12px |

## 9. 动效

| 场景 | 时长 | 缓动 | 说明 |
|---|---|---|---|
| 按钮按下 | 120ms | ease-out | 缩放 0.97 |
| 卡片状态切换 | 200ms | ease-out | 背景色 + 高度过渡 |
| 提示条出现/消失 | 200ms | ease-out | 位移 8px + 透明度 |
| 经验条推进 | 250ms | `cubic-bezier(.2,.8,.2,1)` | 仅宽度 |
| 升级序列 | 600ms | 见 02 文档 6.2 | **全站唯一庆祝动效** |
| 页面切换（Tab） | 0ms | — | **Tab 切换不做转场动画**（孩子会反复点，动画会拖慢） |

**降级**：`@media (prefers-reduced-motion: reduce)` 下所有位移/缩放取消，仅保留透明度与数值变化。

**禁止**：❌ 视差滚动 ❌ 页面级滑动转场 ❌ 循环播放的待机动效（如宠物呼吸动画）——持续动效在低端安卓设备上会明显掉帧，且分散注意力。

## 10. 文案规范

### 10.1 三条铁律

1. **不说教**：不评判孩子的品格与态度，只描述事实与下一步。
2. **不承诺收益**：提交时不说"你将获得 X 颗星星"（星星要等家长确认）。
3. **不制造焦虑**：不出现倒计时、剩余时间、连续中断警告、"别人都完成了"。

### 10.2 替换对照表（实现时直接照抄右侧）

| ❌ 禁止 | ✅ 使用 |
|---|---|
| 你还没完成 | 还没开始 |
| 已逾期 3 天 | 补交 |
| 任务失败 | 没交上去，再点一次 |
| 你落后了 | （删除该表达，不设比较） |
| 连续中断！ | 今天是新的一天 |
| 快去完成任务赚星星 | 今天有 3 件事 |
| 数据同步中 | （不存在此场景） |
| 云端已保存 | 已保存到这台设备 |
| 安全加密保护 | 防止小朋友误点 |
| 密码错误 | 这个码不对，再看看纸上那一行 |
| 操作失败，请重试 | 这次没成功，再点一次 |
| 确定要删除吗？ | 删除后，「朵朵」的记录不再显示（历史任务仍保留） |
| 空数据 | 还没有内容 + 一个下一步按钮 |

### 10.3 标点与格式

- 中文全角标点；数字与中文之间不加空格；`·` 用作信息分隔。
- 按钮文案 2~6 字，动词开头（「我做完啦」「通过」「去备份」）。
- 不使用感叹号堆叠（最多一个，且只在庆祝场景）。
- 时间格式：`今天 08:12` / `昨天 20:30` / `11月17日`。

## 11. 图标规范

| 项 | 规格 |
|---|---|
| 风格 | 线性（stroke 2px，圆角端点），统一 1 种风格 |
